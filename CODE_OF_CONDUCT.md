# Community Code of Conduct

Crossfire is an open technical community welcoming engineers, maintainers, and researchers of all backgrounds.

## Expected Behavior

- Focus technical critiques on code, failure traces, and benchmarks—never on individuals.
- Provide reproducible test cases (ideally minimal Git repo/worktree setups) when reporting bugs or false positives.
- Respect maintainers' and contributors' time by keeping issues and pull requests concise and scoped.

## Unacceptable Behavior

- Harassment, personal attacks, discriminatory language, doxxing, or trolling in issues, pull requests, commit messages, or discussions.
- Deliberately submitting obfuscated code, backdoors, or malicious dependencies.

## Enforcement

Project maintainers may remove, edit, or close comments, commits, issues, and pull requests that violate these standards, and may block repeat offenders from project spaces. To report an issue privately, contact the maintainers listed in repository metadata.
